# Project tools

run_lean.sh checks statement and filled packets and reproduces the upstream and rebuilt raw records. formal.py freezes and verifies full statements, enforces the axiom allowlist and assembles the check-only packet. figures.py reconstructs the six images from the numerical data. tables.py produces each published numerical table. catalogue.py enumerates the statement and source controls. build_exercise.py builds the Word exercise, and extract_sources.py recovers every tagged file from it. release.py writes or checks SHA-256 and creates the ZIP. Rebuilding the document needs pandoc for native editable equations. export_pdf.py invokes LibreOffice and checks the text and background colors on every page, including native equation objects. The PDF distributed here was exported and rendered for inspection.
