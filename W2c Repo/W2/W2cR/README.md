# Formal library

FreeGap, Hessian and Separation are inherited modules recovered from the received Word annex. Rebuilt/A through Rebuilt/F correspond to the six units. Rebuilt/S is a separately frozen supplement. Imports in W2cR.lean expose the complete development. Levels are Def (definition or open predicate), L1 (ordinary mathematical hypotheses), L2 (consumes named premises), and Supplemental (arithmetic fragment). The 77 final names, their sources and their exact statements are printed in the document. Use scripts/run_lean.sh for a local run.
