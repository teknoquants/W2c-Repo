# Eight-part replay

1. Regression of the two supplied upstream W2 Python suites (9579 and 189 assertions).
2. Canonical fibre geometry, 343 rectangles, conditional versions and the horizontal-geodesic counterexample.
3. Linearization obstruction, Gaussian operators, chaos, colour contractions and three open singlet quadratic problems.
4. Exact path enumeration, periodic/open spectra, continuous interval infima and boundary mass.
5. Curvature identities, 80 random Schur tests plus strict examples, kernel tail and validated pinned SU(2) ODE.
6. Variance and energy constants, collapse, concentration, resolvent and conditional W2 assembly.
7. SU(2), SU(3), forty transfer rows and the coupled SU(2) strip benchmark.
8. Book source round trip, exact statement bytes, raw axiom records, table replay, checks per target, figures and manifest.

Run all using the command in the root README. Direct invocation accepts an output directory, e.g. `python3 w2cr_validation/part4.py ../my-results`. Parts use fixed starts or recorded seeds. Part 8 reads earlier outputs and never compiles Lean. Numerical checks validate the displayed identities or calculations with the stated tolerances. Existence claims and uniform estimates need the mathematical argument indicated at their target.
